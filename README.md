# SafeSight — веб-интерфейс камеры

Ветка `WEB` проекта Mosprom-LinQ: FastAPI-сервер и русскоязычная страница с MJPEG-видео, состоянием подключения и кнопкой переподключения. Источник — USB/встроенная камера компьютера, на котором запущен сервер, либо HTTP(S)/RTSP-камера.

Текущий MVP показывает видео. YOLO, LinQ TPU, база событий и авторизация пока не подключены. Файлы из локальных папок `models/` и `tpu_framework_*/` для запуска веба не нужны и исключены из Git.

## Быстрый запуск в Windows (PowerShell)

Нужен Python 3.10 или новее; проверено на Python 3.12. Из корня репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Активация окружения и изменение ExecutionPolicy не требуются. Если Python установлен без `py`, используйте `python -m venv .venv`. Для уже существующего окружения без pip сначала выполните `.\.venv\Scripts\python.exe -m ensurepip --upgrade`.

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Остановить сервер: **Ctrl+C** в терминале. Для другого порта: `run.py --port 8080`; для автоматической перезагрузки при разработке: `run.py --reload`.

Разрешите использование камеры настольными приложениями в **Параметры → Конфиденциальность и безопасность → Камера**. Если камера занята другим приложением, закройте его и нажмите «Подключить заново».

В Windows локальная камера открывается через DirectShow; в macOS — через
AVFoundation. Сетевые HTTP(S)/RTSP-источники используют стандартный backend OpenCV.
При закрытии видеопотока устройство освобождается. Если до этого работал отдельный
просмотр камеры, остановите его перед запуском этого приложения.

## macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

В macOS разрешите камеру своему терминалу в **System Settings → Privacy & Security → Camera**. В Linux проверьте доступ к устройству `/dev/video*`.

## Настройка камеры

По умолчанию используется камера `0`, изображение зеркалируется. Переменные окружения задаются **до запуска** сервера. `.env.example` содержит примеры; `.env` автоматически не загружается.

Windows:

```powershell
$env:CAMERA_SOURCE = '0'
$env:CAMERA_MIRROR = '1'
.\.venv\Scripts\python.exe run.py
```

Сетевая камера в той же сети:

```powershell
$env:CAMERA_SOURCE = 'http://192.168.1.105:8080/video'
$env:CAMERA_MIRROR = '0'
.\.venv\Scripts\python.exe run.py
```

Подставьте реальный адрес своего видеопотока. Для macOS/Linux используйте `export CAMERA_SOURCE='http://...'` и `export CAMERA_MIRROR=0`. Поддержка конкретного сетевого формата зависит от OpenCV/FFmpeg. Для возврата к локальной камере задайте `CAMERA_SOURCE=0`.

## Проверка работы

- `/` — страница просмотра.
- `/health` — работоспособность сервера: `{"status":"ok"}`; доступность камеры не проверяет.
- `/docs` — интерактивная документация API.
- `/video` — MJPEG; возвращает HTTP 503, если камера недоступна или не отдаёт первый JPEG-кадр.

При ошибке на странице отображается сообщение и кнопка повторного подключения. Если видео прервалось во время просмотра, нажмите «Подключить заново». Камера открывается на каждого зрителя: используйте одну вкладку просмотра одновременно. Сервер на другом компьютере использует камеру того компьютера, а не камеру браузера.

Сервер слушает `127.0.0.1`. Для доступа из локальной сети можно указать `run.py --host 0.0.0.0`. Доступ к видео не защищён авторизацией: используйте доверенную частную сеть и не публикуйте порт в интернете.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты проверяют страницу, статику, API, MJPEG, ошибки камеры и освобождение устройства без физической камеры. GitHub Actions запускает их на Windows, macOS и Linux.

## Структура

```text
app.py                      # API, открытие камеры и MJPEG
run.py                      # Запуск с --host, --port и --reload
web/                        # HTML, CSS, JavaScript
tests/test_api.py           # Тесты без оборудования
.github/workflows/tests.yml # CI
.env.example                # Примеры переменных окружения
requirements.txt            # Зависимости сервера
requirements-dev.txt        # Дополнительные зависимости тестов
```

Не добавляйте в Git `.venv`, пароли камер, локальные `.env` и записи видео. Следующий этап — общий захват кадров для нескольких зрителей и подключение инференса LinQ TPU / YOLO.
