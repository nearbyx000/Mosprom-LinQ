# SafeSight / LinQ

**Операторский пульт промышленной безопасности:** видео с камеры, контроль
опасных зон, подтверждение нарушений и журнал с доказательными кадрами.

Система помогает оператору заметить событие и проверить его по сохранённому
кадру. Решения о безопасности и действиях в отношении людей принимает человек.
Это проверяемый пилот с явно обозначенными режимами и ограничениями качества.

## Проверить за минуту — без камеры и TPU

Python 3.12 рекомендуется. Для нового окружения на Windows:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c constraints-tested.txt -r requirements.txt
.\.venv\Scripts\python.exe run.py --mode demo
```

На Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -c constraints-tested.txt -r requirements.txt
python run.py --mode demo
```

Откройте **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.
В Windows используйте `.\.venv\Scripts\python.exe` вместо `python`.
Остановка — Ctrl+C. Демо запускает синтетический источник и цветовой детектор,
**не нейросеть и не TPU**, и по умолчанию пишет отдельный журнал в `data/demo/`.
За 30 секунд показываются вход в зону, отсутствие каски, падение и очистка сцены.

Для настоящей камеры без анализа: `python run.py --mode preview --source 0`.
Для другого порта добавьте `--port 8010`; для отдельного журнала — `--data-dir`.

## Что получает оператор

| Раздел | Назначение |
|---|---|
| **Stream clean** | Чистое непрерывное видео |
| **Stream CV** | Зоны, последние детекции, источник и возраст результата |
| **Warns** | Текущие подтверждённые нарушения; сбои камеры, анализа и записи показаны отдельно |
| **Backlog** | История с фильтрами, источником события, доказательным JPEG и CSV-выгрузкой |

Камера и показ видео независимы от инференса и SQLite. В рабочем `linq` режиме
нейросети выполняются на удалённом **LinQ TPU** через RabbitMQ/JPEG Gateway;
локальная модель не подставляется автоматически. Сопоставляются только результаты
одного кадра и поколения камеры. Старые и повторные ответы отбрасываются.

Событие содержит время захвата, кадр, поколение, источник и SHA256 JPEG.
При временной ошибке SQLite доказательный кадр и намерение записи сохраняются
в дисковой очереди; повторная запись после восстановления не создаёт дубль.

## Готовность функций и честная оценка

| Контур | Статус этой версии |
|---|---|
| Видео, интерфейс, правила зон, история/evidence | Автотесты и отдельный браузерный демо-прогон выполнены |
| YOLOv8n / люди | Локальный ONNX: F1 0.862 на 19 кадрах с проверенной разметкой |
| SafetyVision / падения | Локальный ONNX: 4 из 5 положительных изображений; видео требует отдельной проверки |
| SafetyVision / отсутствие каски | **Экспериментально:** распознано 1 из 5 положительных изображений; строгий IoU-тест рамок не пройден |
| Аппаратная проверка текущей сборки | AMQP handshake недоступен; новых результатов TPU и метрик квантования нет |

Это небольшая интернет-выборка, не оценка качества в конкретном цехе и не
независимый benchmark. [Полный протокол, TP/FP/FN и ограничения](docs/INTERNET20_RESULTS.md).
Показатели синтетических правил не выдаются за точность нейросети.

## Подключить LinQ

1. Оставьте работающие TPU-программы и основной Gateway на месте.
2. Установите `requirements-linq.txt`. Для прямого tensor-протокола дополнительно
   нужен **официальный** `tpu_pycloud_format` организаторов.
3. Скопируйте `.env.example` в `.env`, задайте актуальный `LINQ_JPEG_ROUTE`.
   Для SafetyVision укажите другой `LINQ_SV_ROUTE` из его `GATEWAY READY`.
4. Проверьте конфигурацию и запустите:

```bash
python -m scripts.preflight --mode linq --env-file .env --network
python run.py --mode linq --source 0 --env-file .env
```

Preflight только устанавливает и закрывает AMQP-соединение, **не отправляет
задачи TPU**. Доступность сети не подтверждает точность модели.
Подробности: [инструкция оператора](docs/RUNBOOK.md), [исходники Gateway](gateways/README.md).

## Проверки

```bash
python -m pip install -c constraints-tested.txt -r requirements-dev.txt
python -m pytest -q
node --test tests/detections.test.cjs tests/operations.test.cjs
python -m scripts.preflight --mode demo
python -m scripts.smoke_demo --output data/smoke-new
```

Тесты не открывают физическую камеру и не публикуют задачи на общий TPU.
CI проверяет Python 3.12 на Windows, Linux и macOS и JavaScript на Node.js 22.
Отдельный HTTP smoke запускает 35-секундное синтетическое демо с новой БД,
проверяет три типа событий, MJPEG, CSV и SHA256 всех доказательных кадров.
Optional ONNX-оценка: `requirements-safetyvision-eval.txt`.

## Навигация по репозиторию

```text
safesight/       Web API, pipeline, правила, трекинг, SQLite и evidence outbox
gateways/        Исходники удалённых YOLOv8n и SafetyVision JPEG Gateway
config/          Камера, нормализованные зоны, журнал проверки разметки
scripts/         Preflight, hardware probe, оценка качества и компиляция кандидата
tests/           Автоматические проверки и синтетические fixtures
docs/            Запуск, архитектура, бизнес-сценарий, измерения и передача к защите
tools/legacy/    Исторические probes и патчи; не применять к текущему приложению
data/, models/  Локальные данные/модели, исключены из Git
```

Веса, SDK ZIP, `.env`, VPN-файлы, резервные копии и реальные кадры не входят в
исходную поставку. Их локальные копии сохранены. Лицензия проекта — [GPL-3.0](LICENSE);
условия сторонних моделей и SDK описаны в [THIRD_PARTY.md](THIRD_PARTY.md).
